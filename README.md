# Don't build a slopware factory

Filip Hric's presentation on verification, code review, and continuous improvement in AI software factories.

Published at https://slides.filiphric.com/dont-build-a-slopware-factory/

```sh
npm ci
npm run dev
npm run build
```

Built with Slidev and the local editorial theme. Generated artwork and prompts live in `public/images/`. The closing slide includes verified QR codes for the presentation and contact links.

Publication is managed by the catalog in [filiphric/slides.filiphric.com](https://github.com/filiphric/slides.filiphric.com).
